# MochaTrust | ACM MarketSphere 2026 Prototype

**MochaTrust** is a mobile-first, transparent financial derivatives risk protocol built for retail investors. It bridges global asset exposure through native INR while replacing hidden broker spreads with deterministic AI guardrails and radical cost transparency.

---

## 🚀 Key Features
- **MochaLearn AI Risk Decoder:** A strict structural risk decoder operating under an *"AI Explains, Never Predicts"* protocol.
- **Transparent Monetization:** Itemized, predictable **0.020% platform fee model** with zero hidden slippage.
- **Algorithmic Stress-Testing:** Real-time pre-trade market-shock simulations (-5% to -25%) backed by an automated **95% Margin Safety Score**.
- **Milestone-Locked Growth Loops:** Non-paid organic acquisition loops where users unlock fee discounts and advanced simulation presets through educational milestones.
- **High-Performance Telemetry:** Built on Tailwind CSS and a centralized `window.appState` state machine achieving a **12ms execution runtime**.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS (Mobile-First UI)
- **AI Integration:** Google GenAI SDK (Gemini 2.5-flash)
- **State Management:** Global `window.appState` for real-time cross-screen synchronization.
